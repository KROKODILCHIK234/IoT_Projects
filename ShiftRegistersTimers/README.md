# Проект ShiftRegistersTimers: Управление семисегментными индикаторами через сдвиговые регистры с использованием таймеров

## 1. Введение

### 1.1. Контекст и цель проекта

Данный проект представляет собой реализацию двузначного цифрового секундомера (00-99) на базе микроконтроллера ATmega328P (Arduino Uno). Основная цель — продемонстрировать управление несколькими семисегментными индикаторами через каскадное соединение сдвиговых регистров 74HC595, используя концепцию **неблокирующего выполнения** задач. Проект также реализует управление "тремя процессами" (счет времени, сдвиг битов, защелкивание данных) исключительно через аппаратные прерывания таймера, без использования блокирующих функций `delay()`.

### 1.2. Обоснование выбранного подхода

Традиционные методы управления индикацией (динамическая индикация в основном цикле или использование `shiftOut`) часто блокируют процессор или создают неравномерные временные интервалы при выполнении других задач. В данном решении используется **аппаратный Таймер 1 (Timer1)**, который генерирует прерывания со строгой периодичностью. Внутри прерывания реализован конечный автомат (State Machine), который обеспечивает побитовую передачу данных и счет времени. Это позволяет основному циклу `loop()` заниматься исключительно обработкой пользовательского ввода через Serial, не влияя на точность хода часов.

Для взаимодействия с пинами используется **прямое манипулирование регистрами (Port Manipulation)** (`PORTB`), что обеспечивает максимальную скорость переключения и синхронность сигналов.

### 1.3. Архитектура решения

Система разделена на два независимых слоя:
1.  **Слой реального времени (ISR Timer1)**: Отвечает за инкремент счетчика секунд, кодирование цифр в битовую маску и физическую передачу данных (Clock/Data) на сдвиговые регистры. Передача 16 бит распределена во времени (1 бит за 1 прерывание), что демонстрирует управление процессом через таймер.
2.  **Пользовательский слой (`loop`)**: Слушает Serial-порт, принимает команды установки времени или "подмены" значения (override), безопасно передавая данные в слой прерываний через `volatile` переменные и атомарные блоки.

## 2. Аппаратная конфигурация

### 2.1. Список компонентов

*   Плата Arduino Uno (ATmega328P).
*   2x Сдвиговых регистра 74HC595 (8-бит).
*   2x Семисегментных индикатора (Общий Катод).
*   16x Токоограничивающих резисторов (220Ω).
*   Соединительные провода.

### 2.2. Схема подключения

Используется каскадное подключение регистров: Q7' первого регистра подключен к DS второго.

| Назначение | Пин Arduino | Регистр и бит | Пин 74HC595 |
| :-------- | :---------: | :-----------: | :---------: |
| **Data (DS)** |      8      |      PB0      |     14      |
| **Clock (SHCP)**|      9      |      PB1      |     11      |
| **Latch (STCP)**|     10      |      PB2      |     12      |

**Особенности соединения:**
*   Регистры подключены цепочкой. При передаче 16 бит: биты, отправленные первыми, "проталкиваются" во второй (дальний) регистр, а последние остаются в первом (ближнем).
*   Реализована программная коррекция порядка байт: Младший байт (Единицы) отправляется первым (для дальнего регистра), Старший байт (Десятки) — последним (для ближнего).

## 3. Программная реализация

### 3.1. Конфигурация Таймера1

Используется 16-битный **Таймер1** в режиме CTC (Clear Timer on Compare Match).

*   **Тактовая частота МК (F_CPU):** 16 МГц.
*   **Предделитель (Prescaler):** 64.
*   **Формула расчета OCR1A:**
    `OCR1A = (F_CPU / (Prescaler * TargetFreq)) - 1`
    `(16,000,000 / (64 * 1000)) - 1 = 249`
    Это дает частоту прерываний ровно **1000 Гц (1 мс)**.

### 3.2. Логика обработчика прерываний (ISR)

Обработчик `ISR(TIMER1_COMPA_vect)` выполняет три функции:
1.  **Счетчик времени (ms_counter)**: Считает до 1000 мс для инкремента секунд.
2.  **Логика приложения**: Каждую секунду обновляет значение для отображения (учитывая флаг `override` от пользователя).
3.  **Вывод данных (State Machine)**: Если есть новые данные (`g_bit_index >= 0`), то в каждом прерывании выводится **один бит** данных и подается импульс Clock. После 16-го бита подается импульс Latch.

### 3.3. Ключевой фрагмент кода

```cpp
// Конфигурация Таймера1
void setup_timer1() {
    cli();
    TCCR1A = 0; TCCR1B = 0; TCNT1 = 0;
    OCR1A = 249; // Частота 1000 Гц
    TCCR1B |= (1 << WGM12); // CTC режим
    TCCR1B |= (1 << CS11) | (1 << CS10); // Prescaler 64
    TIMSK1 |= (1 << OCIE1A); // Включить прерывание
    sei();
}

// Обработчик прерывания (упрощено)
ISR(TIMER1_COMPA_vect) {
    g_ms_counter++;
    
    // Логика секунды
    if (g_ms_counter >= 1000) {
        g_ms_counter = 0;
        // Обновление g_seconds и g_shift_buffer...
        g_bit_index = 15; // Старт передачи
    }

    // Побитовая передача (1 бит за цикл прерывания)
    if (g_bit_index >= 0) {
        // Установка Data (PB0)
        if ((g_shift_buffer >> g_bit_index) & 0x01) PORTB |= 1; 
        else PORTB &= ~1;

        // Импульс Clock (PB1)
        PORTB |= 2; PORTB &= ~2;
        
        g_bit_index--;
        
        // Импульс Latch (PB2) в конце
        if (g_bit_index < 0) { PORTB |= 4; PORTB &= ~4; }
    }
}
```

### 4.2. Инструкция для проверки
1.  Запустите симуляцию.
2.  В Serial Monitor введите начальное значение (например, `42`) и нажмите Enter. Счетчик начнет отсчет с 42.
3.  Введите любое другое число (например, `88`). Индикаторы покажут `88` ровно на одну секунду ("глюк"), затем счет продолжится с правильного следующего значения (например, 43, 44...).
