# Автоматизированная калибровка инфракрасного дальномера

Данный проект представляет собой программно-аппаратный комплекс для автоматического сбора данных и построения математической модели калибровки аналогового инфракрасного дальномера (ИК-сенсора). В качестве эталонного измерителя расстояния используется ультразвуковой датчик HC-SR04.

## Цель проекта
Разработать метод и программную реализацию, позволяющую связать "сырые" значения АЦП, получаемые с аналогового ИК-дальномера (например, серии Sharp), с реальным физическим расстоянием в сантиметрах. Процесс сбора данных должен контролироваться ПК, а построение модели (аппроксимация) — происходить автоматически по достижению заданных критериев качества выборки.

## Аппаратное обеспечение
*   Микроконтроллер: **Arduino Uno**
*   Эталонный датчик: **Ультразвуковой дальномер HC-SR04**
*   Калибруемый датчик: **Аналоговый ИК-дальномер** *(В симуляторе Tinkercad заменен на потенциометр из-за отсутствия аналогового ИК-сенсора в библиотеке компонентов)*
*   Индикатор: **Светодиод** (для визуального оповещения об окончании калибровки)

## Логика работы системы

Архитектура проекта разделена на две части: "глупый" сборщик данных (Arduino) и "умный" обработчик (Python-скрипт на ПК).

### 1. Микроконтроллер (Arduino C++)
Микроконтроллер выполняет роль устройства сбора и передачи сырой информации. 
* Ожидает команду `START` по UART (Serial) для начала измерений.
* В цикле опрашивает ультразвуковой датчик (получая эталонное расстояние) и ИК-датчик (получая значение АЦП от 0 до 1023).
* Передает данные на ПК в строковом формате `расстояние,значение_ацп`.
* Ожидает команду `STOP`, после получения которой прекращает передачу и включает светодиод-индикатор.

### 2. Приложение на ПК (Python)
Скрипт на Python полностью управляет процессом:
1.  **Инициализация:** Устанавливает диапазон расстояний для калибровки (например, от 10 до 20 см) и отправляет команду старта.
2.  **Фильтрация:** Принимает поток данных и отбрасывает точки, не входящие в заданный целевой диапазон.
3.  **Контроль качества выборки:** После каждой новой точки массив эталонных расстояний сортируется и проверяется по двум строгим условиям:
    *   *Покрытие:* Собранные данные должны покрывать не менее 90% заданного диапазона `(max - min) * 0.9`.
    *   *Плотность (отсутствие пропусков):* Расстояние между любыми двумя соседними отсортированными точками не должно превышать 2 см.
4.  **Построение модели:** Как только условия выполняются, скрипт останавливает Arduino командой `STOP`. Используя библиотеку `numpy`, производится полиномиальная регрессия (функция `np.polyfit`). Вычисляются коэффициенты для полиномов 1-й, 2-й и 3-й степени для поиска оптимальной функции преобразования `f(АЦП) = Расстояние`.
5.  **Визуализация:** С помощью `matplotlib` строится итоговый график, где на сырые точки накладываются сглаженные кривые полученных математических моделей.
