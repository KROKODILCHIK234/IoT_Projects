## Введение
В данном проекте реализовано решение, позволяющее выполнять **полную калибровку направлений движения "по воздуху"** через Bluetooth-интерфейс без физического вмешательства в схему и без перезаписи кода.

## Технические характеристики системы
*   **Микроконтроллер:** Arduino Uno
*   **Драйвер двигателей:** L293D (H-Bridge)
*   **Интерфейс связи:** UART (Bluetooth HC-05/06)
*   **Управляющее приложение:** ArduinoBluetoothController (режим Gamepad)

## Схема подключения
Для управления моторами используются следующие пины:
*   **Левый мотор:** DIR — 4, SPEED (PWM) — 5.
*   **Правый мотор:** DIR — 7, SPEED (PWM) — 6.
*   **Питание:** Логика 5V (Arduino), Силовая часть 9V (Battery).

## Логика управления и интерфейс (Gamepad)
Для взаимодействия с системой используется 8-кнопочный контроллер со следующей картой команд:

| Кнопка | Символ | Функция в Drive Mode | Функция в Calibration Mode |
| :--- | :--- | :--- | :--- |
| **^** | `F` | Движение вперед | Выбор действия "Вперед" |
| **v** | `B` | Движение назад | Выбор действия "Назад" |
| **<** | `L` | Поворот влево | Выбор действия "Влево" |
| **>** | `R` | Поворот вправо | Выбор действия "Вправо" |
| **X** | `3` | Вход в калибровку | Выход в режим езды (Drive) |
| **Y** | `1` | - | Перебор комбинаций DIR-пинов |
| **A** | `2` | - | **Сохранение** выбранной настройки |
| **B** | `4` | Остановка | Принудительная остановка теста |

## Алгоритм калибровки (Конечный автомат)
Система работает на базе конечного автомата с двумя основными состояниями:

### 1. Режим калибровки (Calibration Mode)
В этом режиме пользователь настраивает соответствие между командой (например, "Вперед") и физическим состоянием пинов DIR1 и DIR2.
1.  Пользователь нажимает кнопку направления (например, `F`).
2.  Платформа начинает вращать моторы, используя текущую комбинацию сигналов (всего 4 варианта: LOW-LOW, HIGH-LOW, LOW-HIGH, HIGH-HIGH).
3.  Если платформа едет не туда (например, крутится на месте), пользователь нажимает кнопку **Y (1)**. Система переключается на следующую комбинацию.
4.  Как только достигнуто нужное движение, нажимается кнопка **A (2)**. Программа запоминает индекс этой комбинации для данного направления.

### 2. Режим езды (Drive Mode)
После настройки всех направлений и нажатия кнопки **X (3)**, система переходит в штатный режим. Теперь при нажатии кнопок управления платформа использует ранее "заученные" индексы комбинаций, обеспечивая корректное движение независимо от того, как изначально были подключены провода.

## Результаты и выводы
Реализованный подход позволяет:
1.  Исключить ошибки монтажа на программном уровне.
2.  Сократить время настройки платформы в 5-10 раз.
3.  Обеспечить гибкость управления без использования ПК во время тестов.

### Как запустить симуляцию:
1.  Перейдите по ссылке в Tinkercad.
2.  Нажмите **Start Simulation**.
3.  Откройте **Serial Monitor**.
4.  Используйте команды: `3` (войти в режим), `F` (начать тест вперед), `1` (менять направление), `2` (сохранить), `3` (вернуться в Drive).
